Alla olevassa ohjelmassa on kolme käännösvirhettä. Korjaa ohjelma niin, että
se kääntyy ja tulostaa kolme riviä.

```csharp
using System;

public class Tervehdys
{
    public static void Main()
    {
        Console.WriteLine("Tervetuloa kurssille!")
        console.WriteLine("Ohjelmointi 1");
        Console.WriteLine("Nähdään luennolla!";
    }
}
```

Yritä ensin ajaa ohjelma sellaisenaan ja lue virheilmoitukset: niissä
kerrotaan rivinumero ja virheen syy. Korjaa virheet yksi kerrallaan ja yritä
ajaa ohjelma jokaisen korjauksen jälkeen, sillä kääntäjä ei välttämättä löydä
kaikkia virheitä yhdellä kerralla.
